# Flow Studio

A local prototype for people who start diagrams in Mermaid and finish them visually in Excalidraw. The agreed flow is source code beside preview, explicit conversion, then editable canvas. Preserve source and each polished draft. Download the final canvas as JPEG or SVG. Natural-language generation comes after this core flow. No provider credentials are supplied.

The user authorized autonomous implementation and validation. Inherit Excalidraw's restrained light editor styling and purple actions, with native canvas controls. Desktop editing is primary; the source and preview stack on narrow windows. Assumption: local browser storage plus downloadable project backups is appropriate for this prototype.
